# Rohit Babbar GitHub Pages website

This folder contains a complete static academic website for:

- `https://rohitbabbar.github.io/`

## Files

- `index.html` — homepage
- `publications.html` — searchable and filterable publications page
- `styles.css` — shared responsive styling
- `script.js` — mobile menu, publication filtering and current year
- `rohit-pic.jpeg` — your existing profile photograph; copy it into this folder

## Deploy

1. Download and unzip the package.
2. Copy `rohit-pic.jpeg` from your existing repository into the same folder.
3. Replace the existing files in the root of the `rohitbabbar.github.io` repository.
4. Commit and push:

```bash
git add .
git commit -m "Redesign academic homepage"
git push
```

GitHub Pages should update automatically.
